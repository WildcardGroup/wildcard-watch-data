# Wildcard Watch data

The generated data behind [Wildcard Watch](https://watch.wildcardgroup.be): which vulnerabilities are being exploited right now, breaches and supply-chain attacks, in plain language. An automated job publishes it every hour.

- **What is here:** only generated files: `data/incidents.json`, `data/archive.json`, `data/calendar.json`, `data/vendors.json`, and the RSS feeds `feed.xml` and `feed-act.xml`. No code, no personal data.
- **Where:** the `gh-pages` branch, served at https://wildcardgroup.github.io/wildcard-watch-data/. It is overwritten on every update and keeps no history. This `main` branch only holds this file.
- **Sources and credits:** CISA Known Exploited Vulnerabilities (CC0), the CVE Program, ENISA EUVD, FIRST EPSS and others; see "How it works" on the site. From news sites and vendor advisories we keep only the headline and a link.
- **Use:** please link to https://watch.wildcardgroup.be rather than to these files; their format can change without notice.
